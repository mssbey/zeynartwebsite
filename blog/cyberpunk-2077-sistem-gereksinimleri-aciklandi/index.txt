<p><strong>Cyberpunk 2077 Sistem gereksinimleri açıklandı!</strong></p>
<p>Son yılların oldukça heyecanla beklenen oyunlarından biri olan, CD Projekt Red’in geliştirmiş olduğu <strong>Cyberpunk 2077</strong> bildiğiniz üzere sadece iki ay gibi bir süre sonra oyuncularla buluşacak.</p>
<p>CD Project, biraz erken davranarak bugün oyunu PC sistem gereksinimlerini açıkladı. Açıklanan sistem gereksinimlerine bakacak olursak düşük sistemler ile rahatça oynanabilecek.</p>
<p><img src="/wp-content/uploads/2020/09/cyberpunk-2077-sistem-gereksinimleri-aciklandi-1-F8RJnKZG.jpg" alt="" loading="lazy" decoding="async"></p>
<p><strong>Cyberpunk 2077 sistem gereksinimleri ise şu şekilde:</strong></p>
<p><strong>Minimum:</strong></p>
<ul>
<li><strong>OS</strong>: 64-bit Windows 7 veya 64-bit Windows 10</li>
<li><strong>DirectX</strong>: DirectX 12</li>
<li><strong>CPU</strong>: Intel Core i5-3570k veya AMD FX-8310</li>
<li><strong>RAM</strong>: 8GB</li>
<li><strong>GPU</strong>: Nvidia GTX 780 3GB veya AMD Radeon RX 470</li>
<li><strong>Depolama alanı</strong>: 70 GB HDD</li>
</ul>
<p><strong>Önerilen:</strong></p>
<ul>
<li><strong>OS</strong>: 64-bit Windows 10</li>
<li><strong>DirectX</strong>: DirectX 12</li>
<li><strong>CPU</strong>: Intel Core i7-4790 veya AMD Ryzen 3 3200G</li>
<li><strong>RAM</strong>: 12GB</li>
<li><strong>GPU</strong>: Nvidia GTX 1060 6B veya AMD Radeon R9 Fury</li>
<li><strong>Depolama alanı</strong>: SSD (70 GB)</li>
</ul>
