Microsoft, Açık Kaynak Kodu İçin Bir Site Yayınladı

Satya Nadella’nın liderliğinde ilerleyen Microsoft, son yıllarda Linux’un düşmanı imajını ortadan kaldırmak ve açık kaynak kodu topluluklarıyla…

Zeynart Web BilişimTasarım & teknoloji notları
15 Ağustos 20201 dk okuma
GENELHizmetlerimiz

Satya Nadella’nın liderliğinde ilerleyen Microsoft, son yıllarda Linux’un düşmanı imajını ortadan kaldırmak ve açık kaynak kodu topluluklarıyla iletişimini güçlendirmek için ciddi çaba sarf ediyor. Windows 10’a bir Linux kerneli koyan Microsoft, GitHub ve yeni Android Surface Duo’ya da bu özelliği eklemişti. 

Genel olarak 30 yıl öncesine kıyasla çok daha farklı bir imaj çizmeyi amaçlayan Microsoft, bazı teliflerini ve fikri mülkiyetlerini de açık kaynak kodu topluluklarıyla paylaşmış, bazı patentlerin de kamu alanında kalmasını sağlamıştı. 

Microsoft’tan yeni internet sitesi

Microsoft, yeni internet sitesini “Açık. İşbirlikçi. Esnek.” olarak tanımladığı açık kaynak kodlu çalışmalara ayırıyor. Bu sitede projelere dahil olmak ya da varolan projeleri keşfetmek mümkün oluyor. 

Microsoft’un attığı adımlar son yıllarda açık kaynak kodlarının büyümesi göz önüne alındığında oldukça mantıklı. Platformlar arasında çalışabilen Visual Studio Code (VS Code) gibi programlar, .NET Core, TypeScript gibi editörler de açık kaynak kodlu çalışmayı daha popüler hale getiriyor. 

Microsoft da bu noktada PowerToys ve Windows Terminal gibi projelerle Windows geliştiricilere açık kaynak kodu desteği sunuyor. Firmanın verdiği rakamlara göre şu anda 35 binden fazla mühendis GitHub Enterprise Cloud kullanarak Microsoft açık-kaynak projeleri yapıyor.

Yeni site perşembe günü duyuruldu

Yeni sitenin duyurusunu, perşembe günü Microsoft Open Source Programs Office’den yazılım mühendisi Jeff Wilcox gerçekleştirdi. Wilcox’un notlarına göre site, GitHub Pages’de de kullanılan Ruby açık kaynak projesi Jekyll ile inşa edildi. 

Microsoft'un yeni sitesinde firmanın açık kaynak konusundaki çalışmalarının ve yaşanan son gelişmelerin yer aldığı bir gönderi kısmı da bulunuyor. Ayrıca topluluk kaynakları, çeşitli lisanslar ve proje yönlendirmeleri de sitede göze çarpan diğer özellikler arasında yer alıyor. Microsoft’un yeni projesi hakkında siz ne düşünüyorsunuz?
