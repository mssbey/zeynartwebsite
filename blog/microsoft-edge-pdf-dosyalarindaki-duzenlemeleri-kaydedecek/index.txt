<p>Microsoft&#39;tan yapılan açıklamaya göre, tarayıcı <strong>Microsoft</strong> <strong>Edge</strong> bundan böyle Native File System API&#39;ı destekleyecek. Bunun İleri Web Uygulamaları&#39;nı (Progressive Web Apps &#8211; <strong>PWA</strong>) ve kullanımını daha ileri bir seviyeye taşıyacağı belirtiliyor. PWA&#39;ların yazılım teslimatının geleceği olduğu belirtilirken yeni adımın oldukça önemli olduğu belirtiliyor.</p>
<p>Native File System API ile birlikte Microsoft Edge, Native File System API aracılığıyla sitelere dosyaları ya da klasörleri <strong>düzenleme</strong> <strong>izni</strong> verilmesini destekliyor. PWA&#39;ların ortaya çıkışı ve uygulanmasıyla birlikte cihazlar arası yazılım teslimatının çok daha kolay hale geldiği belirtiliyor. Bu nedenle birçok web geliştiricisi odağını PWA&#39;lara kaydırmış durumda. Bununla birlikte, PWA&#39;lar ne kadar iyi olursa olsun kendi içlerinde sınırlara sahip ve bu da kullanıcıların native uygulamalar yerine ileri web uygulamaları kullanmalarının önünde bir engel.</p>
<p><strong>PWA&#39;ların, native uygulamaların yerini alması hedefleniyor</strong></p>
<p><img src="/wp-content/uploads/2020/05/microsoft-edge-pdf-dosyalarindaki-duzenlemeleri-kaydedecek-1-s92hlakt.jpg" alt="" loading="lazy" decoding="async"></p>
<p>Yani uzun lafın kısası, PWA&#39;lar native uygulamaların yaptığı her işi yapamıyor. Google, Microsoft ve diğerlerinin <strong>değiştirmeye</strong> çalıştığı şey de bu. Web&#39;de bir şey yapmak isteyenler ancak native&#39;in de kapasitesine sahip olmak isteyenler, web uygulamalarını native wrapper&#39;ların içinde <strong>toplamaya</strong> zorlanıyorlar. Burası tam da Miscrosoft Edge&#39;in Native File System API&#39;ının yardıma geldiği nokta.</p>
<p>Microsoft Edge, Native File System API&#39;ı kullanan native bir <strong>PDF</strong> <strong>düzenleme</strong> desteğini uygulamaya sokuyor. Gelecekte, Microsoft Edge kullanıcıları PDF belgelerinde yapılan düzenlemeleri her seferinde bir kopya kaydetmek yerine kolayca dosyaya kaydedebilecekler.</p>
<p>Google Chrome 83&#39;le başlamak üzere, Native File System API için yeni başlangıç denemesi aralarında Windows, Linux ve macOS&#39;un da bulunduğu tüm masaüstü platformları için başladı. Metin editörü demosunda bunu görmüştük ancak çalıştırabilmek için öncelikle <strong>chrome://flags</strong>&#39;daki Native File System API <strong>deneysel</strong> <strong>özelliğini</strong> etkinleştirmek zorundayız. Bunun ardından google chromelabs.github.io/text-editor&#39;e gidip bir .txt dosyasını yaratarak bilgisayarınıza kaydetmelisiniz. Web uygulamasını kullanarak bilgisayarınıza kaydettiğiniz bir metin dosyasını <strong>düzenleyebilirsiniz</strong>.</p>
