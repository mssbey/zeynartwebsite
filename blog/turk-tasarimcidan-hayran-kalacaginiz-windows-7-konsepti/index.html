Türk Tasarımcıdan Hayran Kalacağınız Windows 7 Konsepti

ABD merkezli teknoloji devi Microsoft, kısa bir süre önce önemli bir devri kapattı. Şirket, yaptığı açıklamalarla yılların emektarı Windows 7…

GENELHizmetlerimiz


ABD merkezli teknoloji devi Microsoft, kısa bir süre önce önemli bir devri kapattı. Şirket, yaptığı açıklamalarla yılların emektarı Windows 7’nin fişini çekti. Windows 7 bugün hala ciddi bir kullanıcı kitlesi tarafından kullanılıyor olsa da Microsoft, kullanıcılara bu işletim sistemiyle ilgili destek sunmuyor. Ancak hem kullanıcıların hem de geliştiricilerin Windows 7 sevdası, kolay kolay bitecek gibi görünmüyor.

Eğer Windows 7 ile ilgili haberlerimizi takip ediyorsanız, “Kamer Kaan Avdan” ismini daha önce duymuşsunuzdur. Türk tasarımcı, geçtiğimiz dönemlerde Windows 7 için oluşturduğu konsept tasarımlarla dikkatimizi çekmişti. Şimdi yeni çalışmasını YouTube kanalı üzerinden paylaşan Avdan, Windows 7’nin 2020 yılında yayınlansa nasıl görünebileceğini gözler önüne seriyor.

Türk tasarımcının Windows 7 tasarımı işte böyle görünüyor

Avdan’ın oluşturduğu 2020 model Windows 7 konsepti aslında, Windows 7’ye ait ögelerin Windows 10 tasarımıyla yeniden harmanlanmasını içeriyor. Tasarımcı, oldukça modern bir konsept oluşturken bir yandan Windows 7’nin ruhunu, diğer yandan da Windows 10’un işlevsel yapısını korumayı başarmış. Bu sayede karşımıza, bugün pek çoğumuzun kullanmak için sıraya geçeceği bir tasarım çıkmış durumda.

Windows 7’nin en sevilen özelliklerinden bir tanesi, kendine has Başlat Menüsü‘ydü. Türk tasarımcı, bunu görmezden gelmeyerek 2020 model Windows 7 tasarımında Başlat Menüsü’ne dokunmamış. Konsept tasarıma genel hatlarıyla baktığımızda, özelleştirilebilen pencere menüleri, Windows 7’deki gibi işlevsel bir Dosya Gezgini, yepyeni simgelerle oluşturulmuş bir Windows 7 görüyoruz. Dilerseniz artık sizleri, Avdan’ın oluşturduğu konsept tasarımla başbaşa bırakalım.
